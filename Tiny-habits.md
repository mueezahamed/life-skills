# Question-2
## How can you use B = MAP to make making new habits easier? What are M, A, and P?

B = MAP means Behaviour = Motivation + Ability + Prompt.It shows that we need motivation, ability and a proper trigger point to build a habit. So, we should start with small and easy steps.

# Question-5
## What is the book's perspective on Identity?

Atomic Habits says that changing our identity is more important than just setting goals. Instead of saying "I want to lose weight", we can think "I am a person who eats healthy and exercises".

# Question-6
## Write about the book's perspective on how to make a habit easier to do?

We should remove things that make the habit difficult.For example, keeping workout clothes ready before sleeping can make it easy to go to the gym in the morning.

# Question-7
## Write about the book's perspective on how to make a habit harder to do?

We should make bad habits difficult to do. For example, uninstalling social media apps or keeping the phone away can help reduce their use.
